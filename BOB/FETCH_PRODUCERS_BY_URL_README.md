# fetch_producers_by_url.js

Genius.comのアルバムページURLから、全トラックのプロデューサー情報を自動取得し、整形されたテキストファイルとして出力するNode.jsスクリプトです。

## 機能概要

- Genius.comのアルバムページURLを指定するだけで、全トラックのプロデューサー情報を自動取得
- トラックリストとプロデューサー情報を見やすく整形
- プロデューサー別の担当曲リストを自動生成（組み合わせ版と個別版の両方）
- 結果をテキストファイルに自動保存

## 使い方

### 基本的な使用方法

```bash
node fetch_producers_by_url.js <GeniusアルバムURL>
```

### 使用例

```bash
node fetch_producers_by_url.js https://genius.com/albums/Addison-rae/Addison
```

## 必要な環境

- Node.js（標準ライブラリのみ使用、追加パッケージ不要）
- インターネット接続

## 出力ファイル形式

スクリプトは `{アーティスト名}_{アルバム名}_producers.txt` という名前でファイルを生成します。

### 出力内容の構成

1. **アルバム情報ヘッダー**
   - アルバム名とアーティスト名
   - 取得日時
   - 総曲数
   - 元のURL

2. **トラックリスト**
   - 各曲のタイトルとプロデューサー情報

3. **Producers（組み合わせ版）**
   - プロデューサーの組み合わせごとに担当曲番号をリスト
   - `&` は `and` に変換
   - 例: `Producer A and Producer B(1,3,5)`

4. **プロデューサー別曲リスト（個別版）**
   - 各プロデューサーが担当した曲番号をリスト
   - 共同プロデュースの場合は両方のプロデューサーに記録
   - 例: `Producer A(1, 2, 3, 5)`

### 出力例

```
アルバム「Addison」- Addison-rae
取得日時: 2026/2/7 20:35:00
総曲数: 12曲
URL: https://genius.com/albums/Addison-rae/Addison
============================================================

1. Diet Pepsi
   Producer: Luka Kloser & Elvira Anderfjärd

2. Aquamarine
   Producer: Luka Kloser

============================================================
Producers
============================================================
Elvira Anderfjärd and Luka Kloser(1,3,5)
Luka Kloser(2,4,6)

============================================================
プロデューサー別曲リスト（個別）
============================================================

Elvira Anderfjärd(1, 3, 5)
Luka Kloser(1, 2, 3, 4, 5, 6)
```

## 主な機能

### 1. URL解析
- Genius.comのアルバムURLからアーティスト名とアルバム名を自動抽出
- URLの妥当性を検証

### 2. トラック情報取得
- アルバムページから全トラックのタイトルとURLを抽出
- 重複を自動除去

### 3. プロデューサー情報取得
- 各トラックページから「Producers」セクションを検索
- 複数プロデューサーの場合は `&` で結合
- プロデューサー情報がない場合は「プロデューサー情報なし」と表示

### 4. レート制限対策
- 各リクエスト間に1秒の待機時間を設定
- Genius.comサーバーへの負荷を軽減

### 5. エラーハンドリング
- 個別トラックの取得失敗時も処理を継続
- エラー発生時は「エラー: 取得失敗」と記録

## 技術的な詳細

### 使用している主な関数

- `fetchHTML(url)`: HTTPSリクエストでHTMLを取得
- `parseAlbumUrl(url)`: URLからアーティスト名とアルバム名を抽出
- `extractTracks(html, artistName)`: HTMLからトラック情報を抽出
- `extractProducers(html)`: HTMLからプロデューサー情報を抽出
- `fetchAlbumProducers(albumUrl)`: メイン処理（全トラックの情報取得）

### データ処理の流れ

1. コマンドライン引数からアルバムURLを取得
2. URLの妥当性を検証
3. アルバムページからトラックリストを取得
4. 各トラックページからプロデューサー情報を取得（1秒間隔）
5. 結果を整形してテキストファイルに出力

## 注意事項

- Genius.comの利用規約を遵守してください
- 大量のリクエストを短時間に送信しないよう、レート制限を設けています
- ネットワークエラーやページ構造の変更により、取得に失敗する場合があります
- プロデューサー情報が記載されていないトラックは「プロデューサー情報なし」と表示されます

## エラーメッセージ

### `使い方: node fetch_producers_by_url.js <GeniusアルバムURL>`
- URLが指定されていません
- コマンドライン引数にGeniusアルバムURLを指定してください

### `エラー: 有効なGeniusアルバムURLを指定してください`
- 指定されたURLがGenius.comのアルバムページではありません
- `https://genius.com/albums/` を含むURLを指定してください

### `曲が見つかりませんでした。URLを確認してください。`
- アルバムページからトラック情報を抽出できませんでした
- URLが正しいか、ページが存在するか確認してください
