# Apple Music 情報取得スクリプト（ブラウザ版）

puppeteer不要！ブラウザの開発者ツールで直接実行できるスクリプトです。

## 特徴

✅ **インストール不要** - Node.jsやnpmは不要  
✅ **シンプル** - ブラウザだけで動作  
✅ **自動ダウンロード** - 結果を3種類のファイル形式で自動保存  

## 取得できる情報

各曲について以下を取得：
- タイトル
- Performing Artist（パフォーマー）
- Composition & Lyrics（作曲者）
- Producer（プロデューサー）
- 時間

## 使い方

### ステップ1: アルバムページを開く

ブラウザ（Chrome、Edge、Firefoxなど）で、Apple Musicのアルバムページを開きます。

例:
```
https://music.apple.com/jp/album/black-british-music-2025/1822840203?l=en-US
```

### ステップ2: 開発者ツールを開く

以下のいずれかの方法で開発者ツールを開きます：

- **Windows/Linux**: `F12` キー または `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`
- **右クリック**: ページ上で右クリック → 「検証」または「要素を調査」

### ステップ3: コンソールタブを選択

開発者ツールの上部にある「Console」（コンソール）タブをクリックします。

### ステップ4: スクリプトを実行

1. `BOB/extract_apple_music_info_browser.js` ファイルを開く
2. **ファイル全体の内容をコピー**
3. コンソールに**ペースト**
4. **Enterキーを押す**

### ステップ5: 完了を待つ

スクリプトが自動的に：
1. トラックリストを取得
2. 各曲のクレジット情報を取得（数分かかる場合があります）
3. 3種類のファイルを自動ダウンロード

## 出力ファイル

### 1. JSON形式 (`*-complete-info.json`)
```json
{
  "albumInfo": {
    "title": "Black British Music 2025",
    "artist": "Various Artists"
  },
  "tracks": [
    {
      "number": 1,
      "title": "曲名",
      "performer": "アーティスト名",
      "composers": ["作曲者1", "作曲者2"],
      "producers": ["プロデューサー1"],
      "duration": "3:45"
    }
  ]
}
```

### 2. テキスト形式 (`*-complete-info.txt`)
```
Black British Music 2025
Various Artists
取得日時: 2026/02/07 21:15:00
================================================================================

1. 曲名
   Performing Artist: アーティスト名
   Composition & Lyrics: 作曲者1, 作曲者2
   Producer: プロデューサー1
   Duration: 3:45
```

### 3. Markdown形式 (`*-complete-info.md`)
```markdown
# Black British Music 2025

**Artist:** Various Artists

### 1. 曲名

- **Performing Artist:** アーティスト名
- **Composition & Lyrics:** 作曲者1, 作曲者2
- **Producer:** プロデューサー1
- **Duration:** 3:45
```

## トラブルシューティング

### ファイルがダウンロードされない

- ブラウザのポップアップブロックを確認してください
- ダウンロード設定で「ダウンロード前に保存場所を確認」が有効になっている場合、3回保存場所を選択する必要があります

### クレジット情報が取得できない

- Apple Musicにクレジット情報が登録されていない可能性があります
- その場合、該当項目は "N/A" と表示されます

### CORS エラーが出る

- このスクリプトはfetchを使用しているため、ブラウザのセキュリティ制限により一部の情報が取得できない場合があります
- その場合は、puppeteer版（`fetch_apple_music_complete_info.js`）の使用を検討してください

### スクリプトが途中で止まる

- ネットワーク接続を確認してください
- ページをリロードして、もう一度実行してください

## 注意事項

- **処理時間**: 曲数が多い場合、完了まで数分かかります（1曲あたり約1秒）
- **レート制限**: Apple Musicのサーバーに負荷をかけないよう、各曲の間に1秒の待機時間を設けています
- **ブラウザ**: Chrome、Edge、Firefox、Safariなどのモダンブラウザで動作します
- **ページを閉じない**: スクリプト実行中はページを閉じないでください

## よくある質問

**Q: 複数のアルバムを一度に処理できますか？**  
A: いいえ、1つのアルバムごとにスクリプトを実行する必要があります。

**Q: 取得したデータを編集できますか？**  
A: はい、ダウンロードされたファイルは通常のテキストファイルなので、任意のエディタで編集できます。

**Q: スマートフォンでも使えますか？**  
A: 理論的には可能ですが、開発者ツールの操作が難しいため、PCでの使用を推奨します。
