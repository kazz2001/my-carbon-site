# アルバムレビューテンプレート使用ガイド

## 📚 概要

`/src/pages/review`フォルダーには、R&B・Hip-Hopアルバムのレビューが格納されています。
新しいアルバムレビューを追加する際は、このテンプレートを使用してください。

## 📁 必要なファイル

各アルバムには**2種類のMDXファイル**が必要です：

| ファイル | 用途 | 説明 |
|---------|------|------|
| **A版** (`*A.mdx`) | 簡易レビュー | 一覧ページや関連レビューで使用する短文レビュー |
| **L版** (`*L.mdx`) | 詳細ページ用 | 個別の詳細レビューページ（スコア、トラックリスト含む） |

## 🚀 クイックスタート

### ステップ1: ファイル名を決める

アーティスト名とアルバム番号を使用してファイル名を決定します：

```
例: "Anderson.Paak / Malibu" (2ndアルバム) → andersonpaak2
例: "Ariana Grande / Eternal Sunshine" (7thアルバム) → arianagrande7
```

作成するファイル：
- `andersonpaak2A.mdx` （簡易レビュー用）
- `andersonpaak2L.mdx` （詳細ページ用）

### ステップ2: 画像を準備

1. アルバムのジャケット画像を用意（JPG形式推奨）
2. `src/images/cd/` フォルダーに配置
3. ファイル名: `andersonpaak2L.jpg` （L版と同じ識別子+L.jpg）

### ステップ3: テンプレートをコピー

#### A版ファイル（`review-template-A.mdx`をコピー）

簡潔な紹介文のみのシンプルな構造：

```mdx
<p>
	Anderson.Paakの2作目。前作の高評価とGuest活動を通した注目度の向上を経て、1年強と短インターバルでのリリースである。
	<br/>そんなこともあって、著名な外部ProducerやGuestを迎えて、よりゴージャスな作品になっている。全体的な雰囲気として、Hip-Hopテイストは残るものの、個々の曲はバンドサウンド指向のR&Bが多めになっている。
	<br/>また、ノリの良いPopで聴きやすい曲も多く、万人受けも期待できる。ところどころで現れるJazz要素や、ひしゃげたVocal、茫洋とした雰囲気が残るところも魅力となっている。
</p>

export default function Layout({ children }) {
  return (
    <>
      {children}
    </>
  );
}
```

**記入項目：**
- アルバムの基本情報（何作目か、前作からの期間など）
- サウンドの特徴、ジャンル
- 制作陣やゲストについて
- 全体的な印象や感想
- 各段落は`<br/>`で改行

#### L版ファイル（`review-template-L.mdx`をコピー）

詳細な情報を含む完全版。以下のセクションで構成：

1. **フロントマター**（メタデータ）
2. **ヘッダー**（タイトル、Best50へのリンク）
3. **メイン情報**（画像、レビュー本文、購入リンク）
4. **スコアカード**（4つの評価指標）
5. **制作情報**（プロデューサー、ゲスト）
6. **トラックリスト**（曲名、作曲者、演奏者、時間）
7. **関連レビュー**（他のアルバムへのリンク）

詳細は`review-template-L.mdx`を参照してください。

## 📋 L版の主要セクション

### 1. フロントマター

```mdx
---
title: "Artist Name / Album Title"
description: "Album Review of Artist Name / Album Title"
keywords: "Artist Name, Album Title, アーティスト名, アルバム名"
---
```

### 2. スコアカード

4つの評価指標（0-10の値）：

```mdx
<SliderJS1 value="5" />  <!-- 評価指標1 -->
<SliderJS2 value="2" />  <!-- 評価指標2 -->
<SliderJS3 value="1" />  <!-- 評価指標3 -->
<SliderJS4 value="9" />  <!-- 総合評価 -->
```

### 3. プロデューサー情報

曲番号を括弧内に記載：

```mdx
<h3>Producers</h3>
<p>
	Organized Noize(1,7,8)
	<br/>DJ Dahi and DJ Kahli(3)
	<br/>Scott Storch(5)
</p>
```

### 4. トラックリスト

Markdownテーブル形式：

```mdx
| No. | Title       | Composers           | Performer        | Time  |
| --- | ----------- | ------------------- | ---------------- | ----- |
| 1   | Track Name  | Composer 1, Comp 2  | Artist Name      | 03:30 |
| 2   | Track Name2 | Composer 1          | Artist feat. X   | 04:15 |
```

### 5. 関連レビュー

他のアルバムへのリンク：

```mdx
import Review1 from "../review/andersonpaak4.mdx";
import Review2 from "../review/andersonpaak3.mdx";

<h3>Other Reviews</h3>

<Row>
  <Column colMd={3} colLg={3} noGutterMdLeft>
    <Review1 />
  </Column>
  <Column colMd={3} colLg={3} noGutterMdLeft>
    <Review2 />
  </Column>
</Row>
```

## 📝 記入例

### A版の記入例

```mdx
<p>
	Ariana Grandeの7作目。前作から4年と過去最長のインターバルであり、本人もその間に30歳を迎えている。そんなこともあって、過去の恋愛や別れを唄いつつ、デビュー以来ひきづっていた少女らしさとも決別した大人っぽい作品になっている。
	<br/>唄のほうも声質や高音の豊かさは維持しつつ、表現力は一段高いところに到達している。
	<br/>制作陣はMax Martinと Ilya Salmanzadehのスウェーデン出身のProducerがメインとなり、USのコンテンポラリーなR&Bとは違った北欧っぽさも感じられ、スローな美メロに流麗なTrackが組み合わさって大人なArianaに寄り添っている。
</p>
```

### L版のレビュー本文例

```mdx
<p>
	Ghana系でNY出身のSinger, Amaaraeの2ndアルバム。矛盾のある表現かもしらないが、都会的なアフロ・ポップという感じで、ただ⑩などは全くそれっぽくはなくて、後半はオルタナロックだし、R&Bや時折Latin, Jazz色も加わった曲もあって、曲調は幅広く、じっくり聴くべき曲も多い。
	<br/>メロディアスに聴かせる曲もあり、Lyricでは、全編、恋愛関係を唄っている。既に29歳ということだが、ころころと可愛らしい声と、こういったTrackとの組み合わせは結構斬新だと思う。
	<br/>⑦では、うっすらと日本語のSEが聞こえ、ラストでは"こんな曲、どうでもいいんですけど"と言ってるように聞こえる。
</p>
```

## 📂 ファイル構造

```
src/pages/review/
├── [artist][number]A.mdx        # 簡易レビュー
├── [artist][number]L.mdx        # 詳細ページ
├── slider1.js                   # スコアカード用コンポーネント
├── slider2.js
├── slider3.js
├── slider4.js
├── adv2.js                      # 広告コンポーネント
└── adv3.js

src/images/cd/
├── [artist][number]L.jpg        # アルバムジャケット画像
└── ...
```

## ⚠️ よくある注意点

1. **画像ファイル名**: L版と同じ識別子に`L.jpg`を付ける（例: `andersonpaak2L.jpg`）
2. **改行タグ**: レビュー本文内の改行は`<br/>`を使用
3. **曲番号の表記**: 丸数字（①②③）または算用数字を使用
4. **Best50リンク**: 該当年のBest50に選出されている場合のみ記載
5. **関連レビュー**: 同じアーティストの他のアルバムや関連作品をリンク
6. **トラックリスト**: 
   - Composersは複数の場合カンマ区切り
   - Performerはfeat.を使用してゲストを表記
   - Timeは`MM:SS`形式

## 💡 レビュー本文の書き方

### 構成例

1. **第1段落**: アルバムの基本情報
   - 何作目か
   - 前作からの期間
   - リリース時の状況

2. **第2段落**: サウンドの特徴
   - ジャンル、スタイル
   - 曲調の傾向
   - 楽器編成やプロダクション

3. **第3段落**: 制作陣とゲスト
   - プロデューサーの特徴
   - ゲストアーティストの貢献
   - コラボレーションの効果

4. **第4段落**: 個人的な感想・評価
   - 印象的な曲
   - 特筆すべき点
   - 総合的な評価

### 表現のバリエーション

**アルバムの位置づけ**
- 「[X]作目のアルバム」
- 「前作から[X]年ぶりのリリース」
- 「デビュー作」「最新作」

**サウンドの説明**
- 「[ジャンル]をベースに」
- 「[要素]と[要素]を融合した」
- 「[形容詞]な雰囲気」
- 「ミドル〰スロー中心」

**制作陣の記述**
- 「[名前]をExecutive Producerに迎え」
- 「[名前]が[X]曲をProduceし」
- 「[名前]などが参加して」

## 🆘 トラブルシューティング

### 画像が表示されない
- 画像ファイルが`src/images/cd/`に配置されているか確認
- 画像パスが`../../images/cd/[filename].jpg`になっているか確認
- ファイル名が`[identifier]L.jpg`になっているか確認

### スコアカードが表示されない
- SliderJSコンポーネントのインポート文があるか確認
- value属性が0-10の範囲内か確認

### トラックリストの表示が崩れる
- Markdownテーブルの区切り文字（`|`）が正しく配置されているか確認
- ヘッダー行と区切り行（`---`）があるか確認
- 各列の数が一致しているか確認

### 関連レビューが表示されない
- インポート文のパスが正しいか確認（`../review/[filename].mdx`）
- インポート名とコンポーネント名が一致しているか確認
- 参照先のファイルが存在するか確認
